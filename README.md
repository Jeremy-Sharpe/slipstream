# Slipstream

Accelerated sales: a frontend prototype for turning calls and emails into CRM
updates, follow-ups, and a continuously improving view of the ideal customer.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Prototype surfaces

- A unified conversation feed for calls and email
- AI summaries, transcripts, and editable follow-up drafts
- Human-approved CRM field write-back
- Aggregate sales and ICP intelligence
- An Origami-ready handoff that generates mock lookalike leads for review

Everything is backed by realistic mock data. The prototype does not connect to
a phone system, read or write a live CRM, call Origami, or send email.
